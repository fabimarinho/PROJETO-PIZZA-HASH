# PizzaHash Landing Page

Landing page estática para a pizzaria PizzaHash, com foco em responsividade, acessibilidade e performance.

## Demo
https://fabimarinho.github.io/PROJETO-PIZZA-HASH/

## Estrutura
```
.
├─ images/
├─ index.html
└─ styles.css
```

## Como executar
Abra `index.html` no navegador.

## Notas
- Os assets estão em `images/`.
- O CSS está em `styles.css`.
